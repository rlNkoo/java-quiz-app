# Quiz Application - README

## Overview

The Quiz Application is a Java-based console application designed to test your knowledge of Java programming. Players start with three lives and answer multiple-choice questions related to Java. The game ends when all lives are lost or all questions are answered.

## Features

- **Three Lives:** Players have three lives to answer questions correctly.
- **Java Knowledge Questions:** A variety of questions covering different aspects of Java programming.
- **Console-Based Interface:** Simple and interactive text-based interface for answering questions.

## Technologies Used

- **Java:** The programming language used to build the application.
- **Java Standard Library:** Utilizes standard Java libraries for console input/output and data management.
